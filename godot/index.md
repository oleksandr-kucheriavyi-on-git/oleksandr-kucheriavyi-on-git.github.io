В рушії GODOT для обробки геометрії Mesh та відображення Mesh в сцені використовується клас RenderingServer. Без цього класу Mesh буде лише набором данних в пам'яті без можливості його візуального відображення та можливості взаємодії з камерою або зі світлом.

Нода з назвою  VisualInstance3D по суті є точкою входу для маніпуляцій з 3д об'єктом. Її найбільш вживана дочірня нода це MeshInstance3D яка дозволяє керувати візуальною взаємодією між Mesh та її матеріалом. Це дозволяє працювати більш інтуїтивно, без необхідності безпосередньо мати справу з технічними деталями процесу рендерингу.

## Типова сцена для відображення 3д
* Створюємо нову сцену
* Створюємо ноду Node3D
* Створюємо MeshInstance3D

MeshInstance3D - нода потрібна для рендерингу будь якого Mesh і відображення його в сцені.
MeshInstance3D – це нода, яка приймає ресурс Mesh та додає його до поточної сцени, створюючи його екземпляр. Цей клас найчастіше використовується для рендерингу 3D-геометрії та може бути використаний для створення екземпляра однієї сітки в багатьох місцях.
