C# — це мова, а .NET — платформа, яка дає їй середовище для роботи: запускає програми, надає бібліотеки та керує пам’яттю.

Умовно:

```text
Твій код C#
   ↓
Компілятор C#
   ↓
Проміжний код IL
   ↓
.NET runtime (CLR)
   ↓
Машинний код для Windows / Linux / macOS
```

Коли ти пишеш програму:

```csharp
Console.WriteLine("Привіт!");
```

відбувається таке:

1. Компілятор C# перевіряє код на помилки та перетворює його не відразу в машинні інструкції, а в проміжний код — IL (Intermediate Language).

2. IL зберігається у збірці — зазвичай це файл `.dll` або `.exe`. Збірка також містить інформацію про класи, методи й використані бібліотеки.

3. Коли програму запускають, її завантажує CLR — Common Language Runtime, тобто середовище виконання .NET.

4. CLR через JIT-компілятор (Just-In-Time) перетворює потрібні частини IL у машинний код саме для комп’ютера, де працює програма. Наприклад, для процесора x64 або ARM.

5. Процесор виконує машинний код, а CLR допомагає програмі: виділяє пам’ять, обробляє помилки, стежить за типами, запускає асинхронні операції тощо.

Найважливіші частини .NET:

- **C#** — мова, якою ти описуєш логіку програми.
- **.NET SDK** — інструменти для створення, збирання й тестування програм. Команда `dotnet build` компілює проєкт, а `dotnet run` — збирає та запускає його.
- **CLR** — середовище виконання, яке запускає зібрану програму.
- **BCL / стандартні бібліотеки** — готовий код для рядків, файлів, мережі, дат, колекцій, JSON тощо. Наприклад, `Console`, `List<T>`, `File`, `HttpClient`.
- **GC, або Garbage Collector** — автоматично звільняє пам’ять від об’єктів, які більше не використовуються.

Наприклад:

```csharp
var names = new List<string> { "Іра", "Максим" };
Console.WriteLine(names[0]);
```

Тут `List<string>` — готовий клас зі стандартної бібліотеки .NET. Пам’ять для списку виділяє CLR, а коли список стане непотрібним, GC зможе її звільнити.

Чому .NET зручний:

- працює на Windows, Linux і macOS;
- має багато готових бібліотек;
- програми зазвичай безпечніші щодо пам’яті, ніж у мовах із ручним керуванням пам’яттю;
- підходить для сайтів, API, десктопних програм, мобільних застосунків, ігор Unity, хмарних сервісів і автоматизації.

Є ще AOT-компіляція: у деяких випадках .NET може заздалегідь перетворити IL у машинний код під конкретну платформу, замість того щоб робити це під час запуску. Це може пришвидшити старт програми.

Найкоротше формулювання: C# описує, що має робити програма; .NET компілює, запускає її та надає необхідні інструменти й бібліотеки.
