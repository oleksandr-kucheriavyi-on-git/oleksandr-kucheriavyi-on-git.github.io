# Концепція єдиної системи типів (Unified Type System)

Фундаментальним будівельним блоком в мові програмування С# є інкапсульована одиниця данних і функцій, яка має назву тип. Будь які існуючі типи, або ті типи які будуть створені в процесі програмування входять до уніфікованої системи типів і в підсумку розділяють загальний базовий тип.

Абсолютно всі типи даних прямо чи опосередковано наслідуються від одного єдиного базового типу, який називається System.Object (або просто object). Кожен тип (вбудований чи створений вами) є нащадком System.Object.

Завдяки цьому єдиному "предку" будь-який об'єкт у C# гарантовано має базовий набір методів, наприклад, ToString() для перетворення у рядок або GetType() для отримання інформації про тип.

## Ієрархія типів у C#

### Типи-значення (Value Types):

* числа (int, double)
* логічний тип (bool)
* символи (char)
* структури (struct) та переліки (enum)

Всі вони спочатку наслідуються від спеціального класу System.ValueType, який, у свою чергу, наслідується безпосередньо від System.Object.

### Посилальні типи (Reference Types):

* класи (class)
* інтерфейси (interface)
* масиви (array) 
* делегати (delegate)

Вони наслідуються від System.Object напряму.

## Boxing та Unboxing

Оскільки object є універсальним базовим типом, змінній типу object можна присвоїти абсолютно будь-яке значення.Коли ви зберігаєте тип-значення (наприклад, int) у змінну типу object, відбувається процес, який називається boxing (пакування). Ваше просте число "загортається" в об'єктну оболонку та переноситься у керовану купу (heap). Зворотний процес називається unboxing (розпакування).

``` C#
int number = 42;          // Звичайне число (Value Type)
object obj = number;      // Пакування (Boxing) — число стало об'єктом!
int copy = (int)obj;      // Розпакування (Unboxing) — повернули число назад
```

## Виняток
Хоча System.Object є вершиною ієрархії для всіх типів, існують специфічні елементи, які стоять дещо осторонь:

Інтерфейси (interface): Вони визначають лише контракти (поведінку) і не можуть наслідувати реалізацію від класу object напряму. Проте будь-який конкретний клас чи структура, які реалізують цей інтерфейс, все одно будуть нащадками System.Object.

Вказівники в небезпечному коді (unsafe code): Покажчики на типи (наприклад, int*) використовуються для прямої роботи з пам'яттю і не беруть участі у загальній системі наслідування .NET.
