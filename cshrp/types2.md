Мова програмування C# має багату та чітко структуровану систему типів. 
Всі типи даних у C# діляться на **два основні види**: 
* **типи значень (Value Types)** 
* **посилальні типи (Reference Types)**

Однак, усередині цих двох видів існує понад **15 вбудованих (базових) типів даних**, а також можливість створювати власні.
---

## 1. Типи значень (Value Types)

Ці типи зберігають безпосередньо саме значення (зазвичай у стеку пам'яті). Якщо ви копіюєте таку змінну, створюється її повна незалежна копія.

### Цілі числа (Integer types)

* `byte` (8 біт, від 0 до 255)
* `sbyte` (8 біт, зі знаком, від -128 до 127)
* `short` (16 біт, від -32,768 до 32,767)
* `ushort` (16 біт, без знаку, від 0 до 65,535)
* `int` (32 біти, **найуживаніший**, від -2.14 млрд до 2.14 млрд)
* `uint` (32 біти, без знаку)
* `long` (64 біти, для дуже великих чисел)
* `ulong` (64 біти, без знаку)

### Числа з плаваючою комою (Дробові)

* `float` (32 біти, точність ~6-9 цифр)
* `double` (64 біти, **стандартний для дробових чисел**, точність ~15-17 цифр)
* `decimal` (128 біт, надвища точність, **ідеальний для фінансових розрахунків**)

### Інші базові типи значень

* `bool` (логічний тип: `true` або `false`)
* `char` (один символ Unicode, наприклад, `'A'` або `'7'`)

### Складні типи значень

* `struct` (структури — дозволяють об'єднувати кілька значень)
* `enum` (перерахування, наприклад, дні тижня або статуси замовлення)

---

## 2. Посилальні типи (Reference Types)

Ці типи зберігають не саме значення, а посилання (адресу) на місце в пам'яті (у купі/heap), де розташовані дані.

### Вбудовані посилальні типи

* `string` (рядок тексту, наприклад, `"Привіт, світе!"`)
* `object` (базовий тип для ВСІХ типів у C#. Будь-яка змінна може бути приведена до типу object)
* `dynamic` (тип, перевірка якого відбувається не під час компіляції, а під час виконання програми)

### Складні посилальні типи

* `class` (класи — основа ООП, на якій будується більшість коду в C#)
* `interface` (інтерфейси, що визначають контракт для класів)
* `delegate` (делегати — посилання на методи)
* **Масиви** (наприклад, `int[]` або `string[]`)

> **Важлива примітка щодо `null`:** > Посилальні типи за замовчуванням можуть приймати значення `null` (відсутність посилання). Типи значень (`int`, `bool` тощо) не можуть бути `null`, якщо тільки ви не зробите їх **Nullable** типами (наприклад, `int?`).


У C# безпека типів є одним із головних пріоритетів, тому мова суворо контролює, як дані одного типу перетворюються в інший. Перетворення типів (Type Casting) ділиться на два основні види: **неявне (implicit)** та **явне (explicit)**.

Ось проста аналогія: неявне перетворення — це як перелити воду з маленької склянки у велике відро (вода точно поміститься), а явне — це спроба перелити воду з відра в склянку (є ризик, що щось розіллється).

---

## Неявне перетворення (Implicit Conversion)

Неявне перетворення відбувається **автоматично** компілятором C#. Вам не потрібно писати жодного додаткового коду.

### Коли воно працює?

1. Коли перетворення є абсолютно **безпечним**.
2. Коли тип даних, *у який* ми конвертуємо, має більший розмір у пам'яті, ніж вихідний тип.
3. Коли немає ризику втратити дані або точність (наприклад, з цілого числа в дробове).

### Приклад у коді:

```csharp
int smallNumber = 12345;
long bigNumber = smallNumber; // Неявне перетворення int у long (автоматично)

float floatNumber = 45.6f;
double doubleNumber = floatNumber; // Неявне перетворення float у double

```

---

## 2. Явне перетворення (Explicit Conversion / Casting)

Явне перетворення потрібне тоді, коли є **ризик втрати даних** або коли компілятор не впевнений у безпеці операції. У такому разі програміст має взяти відповідальність на себе і чітко "наказати" компілятору виконати дію.

Для цього використовується **оператор приведення типів** — круглі дужки `(тип)`, які ставляться перед змінною.

### Коли воно потрібне?

1. Коли ми переходимо від більшого типу до меншого (наприклад, з `double` в `int` або з `long` в `int`).
2. Коли можлива втрата точності (дробова частина просто відсікається).

### Приклад у коді:

```csharp
double pi = 3.14159;
int truncatedPi = (int)pi; // Явне приведення: truncatedPi буде дорівнювати 3 (дріб втрачено)

long bigValue = 3000000000; // Це число завелике для int
int smallValue = (int)bigValue; // Відбудеться переповнення пам'яті, значення спотвориться!

```

## 3. Перетворення між несумісними типами

Якщо ви спробуєте використати звичайне приведення `(int)"123"`, щоб перетворити рядок у число, компілятор видасть помилку. Для несумісних типів (як-от `string` та `int`) у C# є спеціальні інструменти:

### А. Клас `Convert`

Зручний метод, який підтримує перетворення між різними базовими типами:

```csharp
string text = "456";
int number = Convert.ToInt32(text); // Перетворює рядок на int

```

### Б. Методи `Parse` та `TryParse`

* **`Parse()`** — швидко перетворює рядок, але якщо в рядку будуть букви (наприклад, `"123а"`), програма впаде з помилкою.
* **`TryParse()`** — найбезпечніший метод. Він повертає `true` або `false` залежно від того, чи вдалося перетворення, і не викликає аварійної зупинки програми.

```csharp
string input = "999";
// Безпечна спроба конвертації:
if (int.TryParse(input, out int result))
{
    Console.WriteLine($"Успіх! Число: {result}");
}
else
{
    Console.WriteLine("Не вдалося перетворити рядок на число.");
}

```

## 4. Перетворення об'єктів (ООП)

У контексті класів та спадкування також існує два безпечні оператори для явного приведення:

* **Оператор `as**` — намагається привести об'єкт до потрібного типу. Якщо не виходить, він не видає помилку, а просто повертає `null`.
* **Оператор `is**` — перевіряє, чи є об'єкт певного типу (повертає `true/false`).

```csharp
object obj = "Hello World";

// Використання as
string str = obj as string; // str стане "Hello World"

// Використання is
if (obj is string)
{
    Console.WriteLine("Це дійсно рядок!");
}

```

Чи доводилося вам уже стикатися з помилкою `InvalidCastException` (помилка неверного приведення типів) у своїх проєктах, чи ви тільки вивчаєте цю тему?
