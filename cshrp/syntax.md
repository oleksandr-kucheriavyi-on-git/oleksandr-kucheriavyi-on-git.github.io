Якщо потрібно створити ідентифікатор який буде співпадати по назві з існуючим службовим, зарезервованим словом тоді потрібно використати знак @.

```C#
int int = 0; // помилка компіляції
int @int = 0; // Все ок
```

Знак @ можна використовувати і з звичайними назвами, сам знак в назву змінної не входить. Тому викликати таку змінну можна і без знаку @.
```C#
int @myInt = 0;
Console.WriteLine(myInt);
```
