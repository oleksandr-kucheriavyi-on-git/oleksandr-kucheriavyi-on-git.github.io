В мові програмування C# суфікси літералів використовуються для того, щоб чітко вказати комcompiler (компілятору) конкретний тип даних для числового значення. Це допомагає уникнути непевності та помилок приведення типів.

Ось повний список усіх суфіксів літералів у C#, розбитих за категоріями.

---

## 1. Цілочисельні суфікси (Integer Suffixes)

За замовчуванням, ціле число (наприклад, `42`) трактується як `int`. Якщо число занадто велике, компілятор автоматично обирає `uint`, `long` або `ulong`. Проте за допомогою суфіксів можна перевизначити цю поведінку.

| Суфікс | Тип даних | Опис / Приклад |
| --- | --- | --- |
| **`U`** або **`u`** | `uint` | Беззнакове 32-бітне ціле число.<br>

<br>`var unsignedInt = 100U;` |
| **`L`** або **`l`** | `long` | Знакове 64-бітне ціле число.<br>

<br>`var longInt = 100L;` |
| **`UL`** або **`ul`** | `ulong` | Беззнакове 64-бітне ціле число. Можна писати як `UL`, `ul`, `LU`, `lu`.<br>

<br>`var unsignedLong = 100UL;` |

> ⚠️ **Порада щодо стилю:** Завжди краще використовувати велику літеру **`L`** замість маленької `l`, оскільки маленьку `l` дуже легко переплутати з цифрою `1`.

---

## 2. Суфікси чисел з плаваючою комою (Floating-Point Suffixes)

За замовчуванням, будь-яке число з десятковою комою (наприклад, `3.14`) сприймається компілятором як тип `double`. Для інших типів суфікси є обов'язковими.

| Суфікс | Тип даних | Опис / Приклад |
| --- | --- | --- |
| **`F`** або **`f`** | `float` | Число одинарної точності. Обов'язковий, якщо ви ініціалізуєте `float` десятковим значенням.<br>

<br>`float speed = 29.97f;` |
| **`D`** або **`d`** | `double` | Число подвійної точності. Зазвичай необов'язковий, але корисний для чіткості або при роботі з цілими числами, які мають стати double.<br>

<br>`var distance = 100d; // замість 100.0` |
| **`M`** або **`m`** | `decimal` | Число надвисокої точності (ідеально для фінансових розрахунків). **Обов'язковий**, інакше компілятор видасть помилку, намагаючись привести `double` до `decimal`.<br>

<br>`decimal price = 19.99m;` |

---

## 3. Нові суфікси (Починаючи з C# 11)

З виходом C# 11 (продюсер .NET 7) з'явився новий суфікс для покращення роботи з низькорівневим кодом та оптимізації пам'яті.

| Суфікс | Тип даних | Опис / Приклад |
| --- | --- | --- |
| **`u8`** | `ReadOnlySpan<byte>` | Використовується для створення **UTF-8 рядкових літералів**. Замість стандартного UTF-16 (тип `string`), цей суфікс створює рядок, закодований в UTF-8 безпосередньо під час компіляції.<br>

<br>`var utf8Text = "Hello"u8;` |

---

## Цікавий факт (Чого в C# немає?)

На відміну від C++, у C# **немає** суфіксів для типів `short`, `ushort`, `byte` або `sbyte`. Якщо вам потрібно створити літерал такого типу, компілятор робить це автоматично шляхом неявного безпечного приведення (якщо число вміщується в діапазон типу), або ж доводиться використовувати явне приведення:

```csharp
short s = 5; // Працює автоматично (неявне приведення)
var s2 = (short)5; // Очевидне вказання типу через cast

```


Коли ви пишете літерал (просто фіксоване значення у тексті програми, наприклад `42`, `3.14` або `"hello"`), компілятор C# має автоматично призначити йому конкретний тип даних.

Якщо ви не використовуєте жодних суфіксів (як-от `f`, `m`, `L`), C# керується чіткими правилами за замовчуванням. Їх можна розділити на три основні категорії: **цілі числа**, **дробові числа** та **нетекстові/інші літерали**.

---

## 1. Цілочисельні літерали (наприклад: `10`, `5000`)

Для звичайних цілих чисел без десяткової коми компілятор намагається підібрати найменший тип за замовчуванням, **починаючи з `int**`, у який це число фізично здатне вміститися.

Правило працює як «драбина» вниз:

1. Спочатку компілятор дивиться, чи вміщується число в діапазон **`int`** (від -2 147 483 648 до 2 147 483 647). Якщо так — це `int`.
2. Якщо число занадто велике для `int`, але вміщується в беззнаковий **`uint`** — воно стає `uint`.
3. Якщо воно занадто велике і для `uint`, але вміщується в **`long`** — воно стає `long`.
4. Якщо не влазить і туди, але вміщується в беззнаковий **`ulong`** — воно стає `ulong`.

> **Важливо:** Навіть якщо ви напишете маленьке число (наприклад, `5`), компілятор за замовчуванням дасть йому тип **`int`**, а не `byte` чи `short`.

---

## 2. Літерали з плаваючою комою (наприклад: `3.14`, `0.5`)

Для будь-яких чисел, що містять десяткову точку, діє одне залізне правило:

* Тип за замовчуванням — **`double`** (64-бітне число з плаваючою комою).

Це означає, що такий рядок викличе помилку компіляції:

```csharp
float number = 5.5; // ПОМИЛКА: компілятор бачить 5.5 як double і не може записати його у float

```

Щоб змінити цей тип за замовчуванням, якраз і потрібні суфікси (наприклад, `5.5f` для `float` або `5.5m` для `decimal`).

---

## 3. Інші типи літералів

Для символів, текстів та логічних значень типи за замовчуванням є максимально інтуїтивними:

| Приклад літералу | Тип за замовчуванням | Опис |
| --- | --- | --- |
| **`"Hello"`** | **`string`** | Будь-який текст у подвійних лапках. |
| **`'A'`** | **`char`** | Один символ в одинарних лапках (Unicode). |
| **`true`** / **`false`** | **`bool`** | Логічні константи. |
| **`null`** | *Не має типу* | Представляє порожнє посилання (може приводитися до будь-якого nullable або посилального типу). |

---

## Як перевірити тип за замовчуванням на практиці?

Найпростіший спосіб побачити, який тип компілятор призначив літералу — використати ключове слово `var` (яке змушує компілятор самому вивести тип) та метод `.GetType()`:

```csharp
var a = 42;       // Компілятор обере int
var b = 3.14;     // Компілятор обере double
var c = "C#";     // Компілятор обере string
var d = 5000000000; // Це більше за макс. int, тому компілятор обере long

Console.WriteLine(a.GetType()); // Виведе: System.Int32 (це і є int)
Console.WriteLine(b.GetType()); // Виведе: System.Double
Console.WriteLine(c.GetType()); // Виведе: System.String
Console.WriteLine(d.GetType()); // Виведе: System.Int64 (це і є long)

```
