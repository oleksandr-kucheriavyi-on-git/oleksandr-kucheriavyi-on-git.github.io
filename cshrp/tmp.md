## Ключові відмінності

* Успадкування: Клас у C# підтримує лише поодиноке успадкування (можна створити лише один прямий батьківський клас). Інтерфейсів можна реалізувати скільки завгодно.
* Реалізація: Клас зазвичай містить готову логіку (тіла методів, конструктори, поля). Інтерфейс традиційно лише оголошує сигнатури методів, властивостей, подій або індексаторів (хоча з версії C# 8.0 інтерфейси можуть мати реалізацію за замовчуванням).
* Поля та змінні: Клас може мати змінні стану (поля даних). Інтерфейс не може містити полів екземпляра.
* Модифікатори доступу: У класах члени за замовчуванням є private. В інтерфейсах усі члени за замовчуванням є public.

## Порівняльна таблиця

| Характеристика | Клас (class) | Інтерфейс (interface) |
|---|---|---|
| Кількість | Можна успадкувати лише один | Можна реалізувати багато |
| Поля даних | Дозволені (зберігають стан) | Заборонені |
| Конструктори | Є (для створення об'єкта) | Відсутні |
| Логіка / Тіло методів | Обов'язкова (крім abstract) | Опціональна (Default Interface Methods) |

функциональщина

В чистій ООП парадигмі всі функції являють собою методи. В C#  методи це лише різновид функцій-членів куди також відносяться властивості і події. 
Властивості це функції-члени які інкапсулють фрагмент стану об'єкту.
Події це функції-члени які  спрощують виконання дій при зміні стану об'єкту.

Функції можуть розумітися як значення.
За рахунок делегатів можливо передавати функції як значення в інші функції і отримувати їх з інших функцій.

Шаблони.
Ключова особливість функціонального програмування це запобігання використання змінних значення яких змінюються і віддавати перевагу декларативним шаблонам. В C# для цього є можливість створення не іменованих функцій, які можуть захоплювати змінні (лямбда-вирази) і можливість спискового або реактивного програмування через вирази запитів.

Хоча C# історично створювався як об'єктно-орієнтована мова (ООП), сьогодні він є мультипарадигмовою мовою. Вона забезпечує функціональне програмування (ФП) через підтримку першокласних функцій, незмінності даних, виразів замість інструкцій та потужного зіставлення зі зразком. [1, 2, 3, 4] 
Ось головні інструменти C#, які реалізують концепції функціонального програмування:
## 1. Функції як об'єкти першого класу (First-Class Functions)
У ФП функції можна передавати як аргументи, повертати з інших функцій та присвоювати змінним. C# забезпечує це за допомогою: [5] 

* Делегатів (Func, Action, Predicate): Вбудовані типи для збереження посилань на методи.
* Лямбда-виразів: Короткий синтаксис (x, y) => x + y для створення анонімних функцій «на льоту». [3, 4, 5, 6] 
```C#
// Функція вищого порядку, яка приймає іншу функцію як аргумент
int ExecuteOperation(int a, int b, Func<int, int, int> operation) => operation(a, b);
// Виклик із використанням лямбда-виразу
int sum = ExecuteOperation(5, 3, (x, y) => x + y);
```
## 2. LINQ (Language Integrated Query)
LINQ є класичним прикладом декларативного та функціонального підходу в C#. Замість написання циклів for чи foreach для фільтрації чи трансформації масивів, ви описуєте що хочете отримати за допомогою ланцюжка чистих функцій: [3, 4, 7] 
```C#
var numbers = new List<int> { 1, 2, 3, 4, 5, 6 };
// Чиста трансформація без зміни початкового списку
var evenSquares = numbers
    .Where(n => n % 2 == 0)
    .Select(n => n * n)
    .ToList();
```
## 3. Незмінність даних (Immutability)
Функціональний код уникає зміни стану об'єктів після їх створення. В C# для цього є спеціальні конструкції: [7, 8] 

* Записи (records): Спеціальні типи даних (з'явилися в C# 9), орієнтовані на незмінність за замовчуванням.
* Властивості тільки для ініціалізації (init): Дозволяють задати значення лише під час створення об'єкта.
* Вирази with: Замість модифікації об'єкта, вони створюють його копію з новими значеннями. [3, 9] 

```C#
public record User(string Name, int Age);
var user1 = new User("Олексій", 25);// user1.Age = 26; // Помилка компіляції!
// Створення копії зі зміненим полем 
var user2 = user1 with { Age = 26 }; 
```

## 4. Зіставлення зі зразком та вирази (Pattern Matching & Switch Expressions)
У ФП замість блоків інструкцій (if/else) віддають перевагу виразам, які завжди повертають значення. Починаючи з C# 8, конструкція switch може використовуватись як вираз із потужним зіставленням типів та властивостей: [3, 9] 
```C#
decimal GetDiscount(object customer) => customer switch
    {
        User { Age: > 60 } => 0.20m, // Пенсіонери
        User { Age: < 18 } => 0.15m, // Діти
        Company _          => 0.10m, // Корпоративні клієнти
        _                  => 0.0m   // Всі інші
    };
```

## 5. Кортежі (Tuples)
Кортежі дозволяють легко групувати кілька значень і повертати їх із методів без створення окремих важких класів чи структур, що дуже притаманно функціональному стилю. [4, 9] 
```C#
(int Min, int Max) FindRange(IEnumerable<int> nums) => (nums.Min(), nums.Max());
var (min, max) = FindRange(new[] { 4, 1, 9, 3 });
```
